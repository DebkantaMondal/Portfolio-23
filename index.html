Scaling TKE's Sales Configurator Application

TKElevator @ Infosys
2023 — 2026

The Challenge: Under peak windows, the enterprise configuration module suffered from long hours complex data processing, severe thread contention and database timeout spikes.

⚙️ HLD Optimization
  • Used built in threads to process heavy processing jobs in background while keeping main thread free.
  • Replaced bottleneck heavy queries with compiled stored procedures & covering indexes.
  • Implemented Redis for very frequent requests for redundant calculation avoidance.
⚖️ Why This Path?
  • Keep User Experience and Application performance clean and Up always blocking for complex processing tasks.
  • Database-layer tuning preserves strict ACID compliance without introducing cache-invalidation race conditions.
  • Most of our complex calculation's characteristics are coming redundant in nature, so used redis to get the output value of calculation as soon it detects redundant, so that it cuts off engaging threads for background calculation.
📊 Measured Impact
  • Tracked via: App Insights & SQL Execution Plans.
  • Result: Latency dropped from ~340ms to ~190ms (40% faster); throughput scaled +50%.
